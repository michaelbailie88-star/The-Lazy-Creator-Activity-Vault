Facelift · Design System v1

A calmer, braver Vault.

The single source of truth for the facelift: colour with verified contrast, a distinctive type voice, a unique identity for each of the six modules, and one consistent button, card and badge system across the landing page and the app.

Scope guardrails: this page is standalone and changes nothing in index.html, app.html or the licence flow. Every token here maps to CSS variables so the app and landing page can share one system.
